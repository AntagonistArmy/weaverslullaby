## Portable source memory and FLARE

The runnable Python kernel, pinned public Codex snapshot, GitHub source-pull command,
and offline usage are documented in [tools/portable](tools/portable/README.md).
`emitFlare` is exported by `src/lib/field` to record an answer-first target and five
source-addressed evidence branches through the existing durable browser ledger.
The original origin identifier and historical recovery algorithms are preserved.

Repository sync is explicit: `sh scripts/sync-github.sh pull` fast-forwards a
clean current branch; `sh scripts/sync-github.sh push` pushes its committed HEAD.
Application startup preserves the current branch and worktree.

The operational identity is defined in `src/lib/origin.mjs` and checked against
the deployment configuration before development or build can start. The page,
share metadata, install tutorial, and web manifest retain that identity across
hosting domains. Historical event producers, signatures, and ancestry remain
intact. `npm run check:origin` verifies the published origin contract;
`npm test` includes its installation and metadata regression checks.
